# CISSP Certification Quest

A lightweight browser game for practicing CISSP-oriented multiple-choice questions.
Each prompt includes four answers:

- one correct answer,
- one clearly wrong answer,
- two close-but-not-best answers.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
